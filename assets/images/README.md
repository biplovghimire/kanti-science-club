# Where to put your images

Drop your own photos into these folders using the exact filenames referenced
in the JSON files (or update the JSON to match your filenames — see the main
README.md for how the JSON files work).

- images/members/   → profile photos referenced in assets/data/members.json
                       (e.g. president.jpg, em-01.jpg, advisor-01.jpg, alumni-01.jpg)
- images/events/     → event photos referenced in assets/data/events.json
- images/projects/   → project photos referenced in assets/data/projects.json
- images/gallery/    → general club photos used on the About page
                       (about-1.jpg, about-2.jpg, about-3.jpg)

Recommended sizes:
- Member photos: square, at least 400x400px
- Event / project photos: 4:3 or 16:10, at least 800px wide
- Gallery photos: 4:3, at least 800px wide

If an image file is missing or the filename doesn't match, the site
automatically shows a neutral placeholder tile instead of a broken image icon
— so you can add photos gradually without anything looking broken.
